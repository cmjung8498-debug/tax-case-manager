# TaxCaseManager 리포트 생성 순서

## 1. 결제 전 단계

1. 고객 상담내용 또는 입력자료 접수
2. 사건 기본정보 확인
3. A/B/C/D 사건등급 자동 산정
4. 등급별 비용 안내
5. 고객 결제 확인

## 2. 리포트 생성 전 필수 검토

1. 사실관계 추출 결과 확인
2. 법령 기준 DB 확인
3. 법령·국세청·도정법 변경 여부 확인
4. 조정대상지역 기준일별 확인
5. 취득가액 불명확 여부 확인
6. 재개발·재건축 여부 확인
7. 다물건 분리 계산 여부 확인
8. 사건등급 및 수수료 기준 확인

## 3. 리포트 생성

1. 고객용 리포트 생성
2. 부동산용 리포트 생성
3. 세무사용 리포트 생성
4. DOCX 변환
5. 최신성 주석 삽입
6. 세무사 확인 포인트 삽입

## 4. 세무사 송부 패키지

1. 세무사용 리포트
2. 세무사 접수 요약표
3. 고객 위임/성실확인/수수료/최종확인 서류
4. 첨부서류 목록표
5. 증빙서류 분류 폴더
6. 법령 최신성 확인 결과
7. 사건등급 및 수수료 기준
