# TaxCaseManager

TaxCaseManager는 부동산 양도세 사전진단을 위한 업무지원 프로그램입니다.

## 주요 기능

- 고객 작성용 양도세 체크리스트 생성
- 물건 유형별 간편 체크리스트 생성
- 고객 입력자료 JSON/CSV 변환
- 양도세 사실관계 추출
- 취득가액 불명확 검토
- 재개발·재건축/입주권/분양권 고위험 검토
- 조정대상지역 이력 DB 조회
- 고객용/부동산용/세무사용 리포트 생성
- 세무사 전달용 ZIP 패키지 생성

## 주의

본 프로그램은 양도세 사전진단 및 자료정리용입니다.  
최종 세무 판단 및 신고는 세무사 검토가 필요합니다.

## 보안 원칙

이 저장소에는 실제 고객 사건자료, 계약서, 등기부, 녹음파일, 세무사 전달 ZIP, API 키를 포함하지 않습니다.
